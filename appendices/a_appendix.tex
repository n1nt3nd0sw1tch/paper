\chapter{Source Code}
\label{app:code}

The complete source code and dataset for this project is available in this GitHub repository: 
\url{https://github.com/n1nt3nd0sw1tch/thesis}.


\paragraph{GitHub} GitHub was used for version control and experiment management. The repository organises configuration, source data, model responses, analysis, tables, and figures, ensuring that results can be traced back to their code and settings. Dependencies are defined in a pinned environment, and API credentials are stored locally and excluded from version control. All tables and figures are generated programmatically from machine-readable results.
