\centering
\includegraphics[width=\textwidth]{readability_words_type_harmful.pdf}
\caption[Unique Vocabulary, Harmful Scenarios]{Words unique to each disclosure
condition on harmful scenarios, pooled across the panel. Size is the weighted
log-odds ratio against the pooled scenario type as prior, so a word is large
where it is commoner in that condition than the type as a whole predicts. It is
not a frequency, and each panel is scaled to its own strongest word, so sizes
rank within a panel and not across panels; tone carries the same ranking. Each
word is drawn once, at the condition scoring it highest, without which the
vocabulary common to the whole minor range fills every panel and the grid reads
as one cloud repeated. Neutral is placed last, being the reference the eight
explicit ages are read against rather than a rung on the ladder. Listed in
Table~\ref{tab:readability-words-type}.}
\label{fig:words-harmful}
\end{figure}
